## ⚡ Quick Start & Local Setup

### 1. Clone the Repository
```bash
git clone https://github.com/asi-nithin/nitin-asi-portfolio.git
cd nitin-asi-portfolio
```

### 2. Launch Local Server
You can view the portfolio using Python's built-in HTTP server:
```bash
python -m http.server 8080
```
Open your browser and navigate to: [http://localhost:8080](http://localhost:8080)

### 3. Re-generate PDF Resume (Optional)
If you update any resume data or contact info in `generate_resume.py`, run:
```bash
python generate_resume.py
```
This will automatically update `assets/Nithin_Asi_resume.pdf` and ensure it fits on a single A4 page with active hyperlinks.
